# ZARUBA WARDOGS STATS

Чистый Discord-бот статистики WARDOGS: RCON → SQLite → Discord.

Сохраняет игроков, сессии, завершённые матчи, килы, смерти, K/D, часы, победы, Steam-данные, статистику по каждому серверу и общий TOP.

## Награды за бой

- **ДОГИ МЕН** — больше всего килов за один завершённый бой.
- **Скряга** — больше всего заработанных денег за один завершённый бой. Считается сумма только положительных изменений `cash` во время матча; стартовый/перенесённый баланс не учитывается.

В `/top` есть отдельные метрики `ДОГИ МЕН · килы за бой` и `Скряга · заработок за бой`.

## Bothost

Проект готов к запуску на Bothost.

База SQLite должна храниться только здесь:

```text
/app/data/stats.db
```

Папка `/app/data` у Bothost сохраняется между перезапусками и обновлениями из Git.

### Переменные окружения

Минимально нужны:

```env
DISCORD_TOKEN=
DATABASE_PATH=/app/data/stats.db

SERVER_1_NAME=ZARUBA 1
SERVER_1_RCON_HOST=
SERVER_1_RCON_PORT=7776
SERVER_1_RCON_PASSWORD=
SERVER_1_RCON_TLS=false
```

Дополнительно:

```env
DISCORD_CLIENT_ID=
DISCORD_GUILD_ID=
STEAM_API_KEY=
WARDOGS_APP_ID=1867240
POLL_INTERVAL_MS=4000
```

Для серверов 2–4 используются такие же переменные с `SERVER_2_`, `SERVER_3_`, `SERVER_4_`.

Bothost также может передать токен как `BOT_TOKEN` или `DISCORD_BOT_TOKEN` — бот понимает все три варианта.

### Деплой

1. Выбрать Node.js / Discord.
2. Указать GitHub-репозиторий и ветку.
3. Включить **«Использовать собственный Dockerfile»**.
4. Добавить переменные окружения.
5. Запустить/перезапустить бота и открыть логи.

При старте в логах появятся путь к SQLite, список подключённых WARDOGS-серверов и Discord-аккаунт бота.

## Локальный запуск

```bash
npm install
npm start
```
